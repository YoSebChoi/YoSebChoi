# 노포 지도 — 백년가게 · 백반기행 맛집 지도

내 위치, 또는 지도에서 검색하거나 옮겨 간 곳을 중심으로 **백년가게**(중소벤처기업부 지정 음식점)와
**허영만의 백반기행** 맛집을 가까운 순서로 보여 주는 웹앱(PWA)입니다.

- 주소: `https://<GitHub 아이디>.github.io/<저장소>/matjip/` (GitHub Pages가 `docs/`에서 배포될 때)
- 휴대폰 브라우저에서 열고 "홈 화면에 추가"하면 앱처럼 쓸 수 있어요.

## 쓰는 법

| 하고 싶은 것 | 방법 |
| --- | --- |
| 내 주변 식당 보기 | 오른쪽 아래 ⌖ 버튼 (위치 권한 허용) |
| 다른 동네 보기 | 지도를 끌어서 옮기기 — 화면 가운데 ＋ 기준으로 목록이 바뀜 |
| 장소로 이동 | 위 검색창에 동네·역·주소를 넣고 검색 → "장소" 결과 선택 |
| 식당 이름으로 찾기 | 검색창에 입력하면 바로 "노포" 결과가 뜸 |
| 목록 골라 보기 | 전체 / 백년가게 / 백반기행 / 둘 다 |
| 길찾기 | 식당을 누르고 길찾기 · 카카오맵 · 네이버 지도 |
| 저장 | 식당에서 ★ 가고 싶어요 / ✓ 가 봤어요 → 위 「★ 저장」 칩으로 모아 보기 (이 폰에만 저장) |
| 공유 | 식당에서 공유 버튼 → 받은 사람이 링크를 열면 그 식당이 바로 열림 |
| 종류 | 「종류」 칩에서 한식 · 국밥·탕 · 면 · 고기 · 해산물 · 중식 · 일식·양식 · 빵·카페 |
| 제보 | 목록 맨 아래 「빠진 식당 제보하기」 → GitHub 이슈로 접수 |

## 데이터

`matjip/data/`

| 파일 | 내용 |
| --- | --- |
| `baekban.csv` | 백반기행 식당 (상호, 주소, 메뉴, 방송, 출처). 공식 목록이 없어 기사로 확인한 곳만 담았어요. 줄을 더하면 지도에 반영돼요. |
| `baeknyeon_seed.csv` | 공식 목록을 넣기 전까지 쓰는 백년가게 몇 곳 |
| (공식 백년가게 CSV) | 공공데이터포털의 **소상공인시장진흥공단_전국 백년가게 지정리스트 현황 정보** CSV를 이 폴더에 그대로 올리면 돼요. 파일 이름은 상관없어요. 열 이름(업체명·주소·업종 등)은 자동으로 알아보고, 업종을 보고 음식점만 남겨요. |
| `geocode_cache.json` | 주소 → 좌표 기록 (자동 생성) |

### 업데이트 흐름

1. `matjip/data/`에 CSV를 올리거나 고쳐서 커밋해요 (GitHub 웹에서 "Add file → Upload files"도 돼요).
2. GitHub Actions의 **노포 지도 데이터 빌드**가 새 주소의 좌표를 찾고 `docs/matjip/`을 다시 만들어 커밋해요.
3. 좌표 찾기
   - 저장소 Settings → Secrets → Actions에 `KAKAO_REST_KEY`(카카오 디벨로퍼스 REST API 키)를 넣으면 카카오 주소 검색을 써요. 한국 주소는 이쪽이 훨씬 정확해요.
   - 키가 없으면 OpenStreetMap(Nominatim)을 써요. 초당 1건이라 1,500곳이면 30분 정도 걸리고, 번지를 못 찾으면 길 위치로 대략 표시해요(앱에서 흐린 점).

### 카카오 키 (저장소 Settings → Secrets → Actions)

| 이름 | 쓰임 |
| --- | --- |
| `KAKAO_REST_KEY` | 주소 → 좌표, 백반기행 수집(카카오맵 방송 정보), 백년가게 영업 확인·업종 |
| `KAKAO_JS_KEY` | 앱 안의 장소 검색을 카카오로 (카카오디벨로퍼스 JavaScript 키, JavaScript SDK 도메인에 `https://yosebchoi.github.io` 등록) |

빌드는 매달 2일 새벽에도 자동으로 돌아서 새로 등록된 백반기행 식당을 받고, 카카오맵에서 찾을 수 없게 된 백년가게에 「확인 필요」 표시를 붙여요.
빌드 뒤에는 실제 브라우저로 앱을 열어 지도 그림과 식당이 제대로 나오는지 확인하고, 문제가 있으면 반영하지 않아요.

직접 빌드하려면:

```sh
pip install pillow
KAKAO_REST_KEY=... python3 matjip/build.py   # 키 없이도 됨
python3 matjip/build.py --offline            # 좌표 기록만으로 빌드
```

## 참고

- 지도: OpenStreetMap 타일 + Leaflet. 장소 검색: OpenStreetMap Nominatim.
- 방송 뒤 이전·폐업한 곳이 있을 수 있어요. 가기 전에 지도 앱에서 영업 여부를 확인하세요.
