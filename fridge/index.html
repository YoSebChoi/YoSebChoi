      냉장고에 뭐가 있나요?

      있는 재료를 눌러 담아요. 다시 누르면 빠져요.

      설정

      추천과 찾기에서 이 재료가 들어간 요리를 빼요. 매운 음식, 해산물 같은 묶음은 「추천」 탭의 「빼고 싶은 것」에서 골라요.

      AI 기능 (선택)

      레시피 추천은 키 없이 앱에 담긴 레시피 DB로 돼요. 여기에 Anthropic API 키를 넣으면 사진으로 재료 찾기, AI 셰프의 메뉴 추천, 웹에서 출처 있는 레시피 찾기가 더해져요. 안 넣어도 괜찮아요.

      AI 모델
      키 만드는 법
      1. console.anthropic.com에 가입하고 결제 수단을 등록해요.
      2. API Keys에서 「Create Key」를 눌러 만든 키를 복사해요.
      3. 위 칸에 붙여 넣고 「저장」을 눌러요.

      키는 이 폰에만 저장되고 Anthropic 말고는 어디에도 보내지 않아요. 요금은 내 계정에 쓴 만큼 나와요. 대략 사진으로 재료 찾기 40원, 메뉴 추천 50원, 레시피 찾기(웹 검색 포함) 200~500원 정도예요 (Opus 기준, Sonnet은 절반쯤). 한 번 찾은 레시피는 다시 열어도 요금이 들지 않아요.

      새 버전이 나왔어요

      업데이트해도 저장한 레시피와 설정은 그대로 남아요.
