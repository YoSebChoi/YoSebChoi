# 최책임의 예비맘 혜택 지도

임산부에게 할인·줄 없이 입장·선물을 주는 **식당·뷔페, 카페, 베이커리, 호텔, 리조트**를 지도에 모으고,
**정부·지자체 임신 지원**을 따로 모아 보는 웹앱(PWA)이에요. 노포 지도와 같은 방식으로 만들었어요.

- 주소: https://yosebchoi.github.io/YoSebChoi/mom/
- 휴대폰 브라우저에서 열고 "홈 화면에 추가"하면 앱처럼 쓸 수 있어요.

## 쓰는 법

| 하고 싶은 것 | 방법 |
| --- | --- |
| 내 주변 혜택 | 오른쪽 아래 ⌖ 버튼, 또는 첫 화면 「내 주변 혜택 찾기」 |
| 종류별로 모아 보기 | 위 아이콘 칩(식당·뷔페 · 카페 · 베이커리 · 호텔 · 리조트) → 그 종류를 전국에서 가까운 순으로 |
| 혜택 내용 보기 | 지도 핀이나 목록을 누르면: 임산부 혜택, 기간, 조건, 준비물, 출처(네이버 블로그 · 기사 · 공식 · 매장 공지)와 날짜 |
| 지금 받을 수 있는 곳만 | 「진행 중만」 칩 (기간이 끝난 곳은 「종료·기록」으로 남겨 둬요) |
| 정부·지자체 지원 | 「지원 정책」 칩 → 전국 공통 / 시·도별 |
| 블로그 후기 | 「블로그 후기」 칩 → 2024년 이후 네이버 블로그 글 모음. 매장 이름이 들어간 글은 그 매장 화면에도 붙어요 |
| 저장 · 공유 | 매장에서 ★ 가고 싶어요 / ✓ 다녀왔어요(이 폰에만 저장) · 공유 버튼 |
| 제보 | 목록 맨 아래 「혜택 매장 제보하기」 → GitHub 이슈 |

## Android 앱 (APK)

`mom-app/`은 이 웹앱을 띄우는 Android 앱(Capacitor)이에요. 웹을 고치면 앱에도 바로 반영돼요.

- 받기: https://github.com/YoSebChoi/YoSebChoi/releases/download/mom-apk/mom-map.apk
- 빌드: GitHub Actions **예비맘 혜택 지도 APK** (`mom-app/`이 바뀌면 릴리스 `mom-apk`에 올려요). 서명은 노포 지도와 같은 `ANDROID_SIGNING` 비밀값.
- 앱을 열면 릴리스의 `mom-map.json` 빌드 번호와 비교해서 새 버전을 앱 안에서 설치해요.

## 데이터

`mom/data/`

| 파일 | 내용 |
| --- | --- |
| `places.json` | 혜택 매장. 모든 혜택에 `src`(출처 종류 · 이름 · 날짜 · 링크)가 있어요. `st`: 진행 중 / 기간 한정 / 종료 |
| `policies.json` | 정책 탭 (전국 공통, 시·도별) |
| `blog.json` | 네이버 블로그 글(제목 · 링크 · 날짜 · 블로그 ID · 검색 요약). `fetch_blog.py`가 모아요 |
| `blog_candidates.json` | 블로그 본문을 읽고 정리한 혜택 매장 후보(`n` 이름 · `c` 종류 · `a` 주소 · `perk` 혜택 · `cond` 조건 · `bring` 준비물 · `period` 기간 · `seen` 마지막 확인일 · `existing` 기존 매장 여부 · `confidence` high/medium/low · `src` 글 URL·날짜·블로그 ID·제목). 검토해서 `places.json`에 옮겨요. low는 넣지 않아요 |
| `geocode_cache.json` | 매장 → 좌표 (카카오 키가 있을 때 자동) |

### 네이버 블로그 수집

GitHub Actions **예비맘 혜택 블로그 수집**이 매주 월요일 새벽에 「임산부 할인」, 「임산부 프리패스」, 「산모수첩 할인」,
「○○ 임산부 혜택」(시·도별) 같은 말로 2024년 이후 글을 찾아요. 저장소 Settings → Secrets → Actions에 키가 있어야 해요.

| 이름 | 쓰임 |
| --- | --- |
| `NCP_API_KEY_ID`, `NCP_API_KEY` | NAVER API HUB(네이버 클라우드) 블로그 검색 |
| (또는) `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET` | 네이버 개발자센터 검색 API |

직접 돌리려면(네이버에 접속되는 곳에서): `python3 mom/fetch_blog.py` → `python3 mom/build.py`

## 참고
