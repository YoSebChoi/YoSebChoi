# 임테기 시약선 진하기 추정 (T/C ratio)

사진 한 장에서 **대조선(C)** 과 **시약선(T)** 의 광학 밀도(OD)를 측정해
`T/C` 비율로 시약선이 대조선 대비 얼마나 진한지 추정한다.

## 원리

1. 분홍/자주색 손잡이(“HCG” 인쇄부)를 찾아 스트립 방향과 폭을 잡는다.
2. 스트립을 수평으로 회전하고, 손잡이 옆 반응창 구간의 가로 프로파일(스트립 폭 방향 중앙값)을 만든다.
3. 각 위치의 밝기를 국소 배경 대비 광학 밀도로 변환한다: `OD = -log10(I / I_배경)`.
   - 기본 신호 `g-r` = 녹색 OD − 적색 OD. 금 콜로이드 선(자주/분홍)은 녹색을 강하게 흡수하지만,
     검은 인쇄(MAX 표시), 그림자, 접힌 자국은 무채색이라 상쇄된다.
   - 교차 확인용으로 순수 녹색 OD 비율(`ratio_peak_green`)도 함께 보고한다.
4. 손잡이에 가장 가까운 뚜렷한 선 = **C**, 그보다 흡수부 쪽(스트립 폭의 0.5~3배 거리)에서 가장 강한 피크 = **T**.
5. `ratio_peak = OD_T / OD_C` (피크 높이), `ratio_area` (선 면적 비) 와 노이즈 기반 SNR을 계산한다.

## 사용법

```bash
python3 .claude/skills/hcg-line-ratio/scripts/analyze_strip.py <사진> --debug <출력.png>
```

옵션
- `--debug out.png` : 잘라낸 스트립 + OD 프로파일 + C/T 위치 표시 이미지. **항상 생성해서 Read로 직접 확인**한다.
- `--channel g` : 순수 녹색 OD 사용 (`g-r` 결과와 비교용).
- `--box x0,y0,x1,y1 [--control-side left|right]` : 자동 검출이 실패할 때(손잡이가 분홍색이 아니거나 잘렸을 때)
  수평으로 놓인 반응창 영역을 직접 지정. 박스 높이는 스트립 폭 정도로.
- `--json` : 한 줄 JSON 출력.

의존성: `numpy`, `Pillow` 만 필요.

## 작업 절차

1. 사진 파일 경로를 확인한다 (대화에 첨부된 이미지는 업로드 경로 사용).
2. 스크립트를 `--debug` 와 함께 실행한다.
3. 디버그 이미지를 Read로 열어 검증한다:
   - 파란 C 선이 실제 대조선 위에, 주황 T 선이 시약선 위치에 있는지
   - 엉뚱한 곳(MAX 검은 막대, 반응창 테두리, 펜 자국)을 잡지 않았는지
   - 틀렸다면 원본 이미지에서 반응창 좌표를 추정해 `--box` 로 재실행한다.
4. 여러 장이면 각각 실행하고 표로 비교한다 (날짜/시간 순 진하기 변화 확인 등).
5. 아래 형식으로 답한다.

## 결과 해석

| ratio_peak | grade | 표현 |
|---|---|---|
| T 미검출 (SNR < 5) | none | 시약선 확인 안 됨 (`upper_bound_ratio` 이하) |
| < 0.10 | very faint | 매우 희미 (대조선의 ~10% 미만) |
| 0.10 – 0.30 | faint | 희미 |
| 0.30 – 0.60 | medium | 중간 |
| 0.60 – 0.90 | strong | 진함 |
| ≥ 0.90 | equal-or-darker | 대조선과 비슷하거나 더 진함 |

`ratio_peak`, `ratio_area`, `ratio_peak_green` 이 서로 비슷하면(±30% 이내) 신뢰도가 높다고 보고,
크게 다르면 조명·초점·선 번짐 문제를 의심한다고 말한다.

답변 예시:

> 시약선은 대조선 대비 약 **13%** (피크 0.129 / 면적 0.131 / 녹색채널 0.135) 진하기로, ‘희미한 두 줄’ 수준입니다. SNR 24로 노이즈보다는 확실히 높습니다.

## 반드시 함께 전달할 주의사항

- **의료 진단이 아니다.** 사진 기반 상대 비교일 뿐이며, 판정과 임신 여부 확인은 병원 혈액검사(β-hCG)로 한다.
- T/C 비율은 hCG **농도(mIU/mL)로 환산되지 않는다.** 대조선 진하기 자체가 스트립·로트마다 다르다.
- 제품 설명서대로 **3~5분 안에 판독한 사진**만 의미가 있다. 이후 생기는 증발선(evaporation line)은 회색빛이며 판정 불가.
- 다른 날 결과를 비교할 때는 **같은 제품, 같은 조명, 같은 시간대(소변 농도), 같은 판독 시간**에 찍은 사진끼리 비교해야 한다.
- 스마트폰 HDR/보정, 그림자, 반사, 초점 흐림이 수치를 바꾼다. 균일한 자연광·정면·초점 맞춤 촬영을 권장한다.
