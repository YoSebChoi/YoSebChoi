잘 찍는 법
  • 검사 후 5~10분 사이에 찍은 사진만 의미가 있어요. 판독 타이머를 쓰면 편해요.
  • 그림자 없이 밝은 곳에서, 정면으로, 초점을 맞춰 찍어 주세요.
  • 분홍색 HCG 손잡이가 사진에 다 나오게 찍으면 스트립을 자동으로 찾아요.
  • 사진 찍기는 카메라가 바로 열려요. 타이머가 울릴 때 눌러 찍으면 편해요.
  • 버튼을 눌러도 앨범이 안 열리면, 링크를 크롬 같은 브라우저에서 열어 주세요.
